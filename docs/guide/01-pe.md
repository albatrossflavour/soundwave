# 1. Prepare PE

## Why

Soundwave pushes to PE's Vulnerability Remediation service on TCP 8146 of the primary, with an RBAC token. A blocked port doesn't show up until the first push, so check it now.

## Before you start

- Vulnerability Remediation enabled in PE
- No other vulnerability integration registered with PE. PE accepts one, so run one Soundwave and add each scanner as a cassette

## Do it

Create a PE RBAC token for a user whose role can push to Vulnerability Remediation (an administrator's can), with a long lifetime, because Soundwave uses it on every run and an expired token stops the push. On the primary, logged in as that user:

```sh
puppet access login --lifetime 1y --print
```

Encrypt the token it prints with eyaml.

## Done when

From the scanner node, against the PE primary:

```sh
curl -sk -o /dev/null -w '%{http_code}\n' --max-time 10 https://<primary>:8146/
```

Any HTTP status, such as `404`, means the port is open. `000` means it isn't, so check the security group or firewall between the scanner and the primary, and that `<primary>` resolves to the right address from the scanner.

## If it fails

The primary's name as the scanner resolves it must be the one you'll push to. Soundwave defaults to the server that compiled its catalogue, which is wrong when that's a compiler. See `pe_host` in [Parameters](../../README.md#parameters).
